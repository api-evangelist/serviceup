# ServiceUp

> ServiceUp is an agentic vehicle repair and maintenance platform for commercial fleets, insurance carriers and repair shops. It centralizes the repair lifecycle — intake, shop routing, estimate and invoice approval, status tracking and payment — across collision, mechanical and preventative maintenance work, and runs AI Repair Agents over it in manual, co-pilot or autopilot modes.

ServiceUp does not publish an llms.txt, a developer portal, an API reference, or an OpenAPI
definition. This file is generated by API Evangelist from the ServiceUp public website and from
live probes of ServiceUp's own hosts. It is NOT published by ServiceUp.

The one machine-readable API surface ServiceUp operates is an OAuth-protected Model Context
Protocol server. It is undocumented publicly and was found by probe.

## API surface

- [ServiceUp MCP Server](https://api.serviceup.com/mcp): Live MCP endpoint (streamable HTTP). Returns HTTP 401 anonymously with an RFC 9728 `WWW-Authenticate` Bearer challenge. Requires an OAuth 2.1 access token with `mcp:read` and/or `mcp:write`. The tool list is auth-gated and is not recorded anywhere in this profile.
- [OAuth protected-resource metadata](https://api.serviceup.com/.well-known/oauth-protected-resource/mcp): RFC 9728. Names `https://auth.serviceup.com` as the authorization server and `mcp:read` / `mcp:write` as scopes.
- [OAuth authorization-server metadata](https://auth.serviceup.com/.well-known/oauth-authorization-server): RFC 8414. Authorization code + refresh token, PKCE S256, scopes `mcp:read`, `mcp:write`, `offline_access`. No dynamic client registration endpoint.
- [JWKS](https://auth.serviceup.com/api/auth/jwks): One EdDSA / Ed25519 signing key.
